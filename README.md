# Corporate Financial Health & Working Capital Analysis

## Overview

This project is an end-to-end financial analytics platform that uses SEC Company Facts data to analyze public companies across revenue growth, profitability, working capital, free cash flow, forecasting, scenario analysis, SQL querying, and dashboarding.

The project started with Walmart and expanded into a deployed Streamlit dashboard with dynamic SEC ticker analysis. Users can enter a ticker, check which financial analyses are supported, view business-model-aware guidance, analyze financial trends, and export a consolidated CSV.

## Core Features

- Fetches SEC Company Facts data for configured companies.
- Cleans annual financial statement data.
- Handles duplicate SEC periods by keeping the latest filing.
- Calculates profitability, working capital, and free cash flow metrics.
- Builds multi-company comparison datasets.
- Creates a SQLite database for querying financial metrics.
- Supports dynamic ticker lookup for SEC-registered companies.
- Checks which metrics are available for each ticker.
- Provides industry-aware guidance so retail metrics are not blindly applied to banks, insurers, or software companies.
- Generates simple revenue forecasts using interpretable baseline models.
- Deploys as a public Streamlit dashboard.
- Allows users to download analysis CSVs.
- Includes automated tests for key financial outputs.

## Key Metrics

The project calculates:

- Revenue growth
- Operating margin
- Days Sales Outstanding (DSO)
- Days Inventory Outstanding (DIO)
- Days Payables Outstanding (DPO)
- Cash Conversion Cycle (CCC)
- Operating cash flow
- Capital expenditures
- Free cash flow
- Free cash flow margin
- Revenue forecasts
- Scenario analysis outputs

Core formulas:

DSO = Average Accounts Receivable / Revenue * 365

DIO = Average Inventory / Cost of Revenue * 365

DPO = Average Accounts Payable / Cost of Revenue * 365

CCC = DSO + DIO - DPO

Free Cash Flow = Operating Cash Flow - Capital Expenditures

## Dynamic Ticker Analysis

The dashboard allows users to enter an SEC ticker such as AAPL, MSFT, JPM, WMT, COST, or TGT.

For each ticker, the app checks SEC tag availability and determines which analyses are supported.

Dynamic analysis currently includes:

- company lookup by ticker
- supported metric check
- industry-aware profile guidance
- revenue and operating margin analysis
- free cash flow analysis when available
- working-capital analysis when available
- simple revenue forecast
- consolidated CSV export

This matters because not all companies report the same SEC tags. A retailer may support inventory and cash conversion cycle metrics, while a bank usually should not be analyzed with retail working-capital metrics.

## How to Run Locally

Create and activate a virtual environment:

python3 -m venv .venv
source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Run the full pipeline:

python -m src.data.run_pipeline

Run tests:

pytest

Launch the dashboard:

streamlit run app/dashboard.py

## Individual Pipeline Commands

Fetch SEC data:

python -m src.data.fetch_data walmart
python -m src.data.fetch_data target
python -m src.data.fetch_data costco

Check tag compatibility:

python -m src.data.check_tags walmart
python -m src.data.check_tags target
python -m src.data.check_tags costco

Clean data:

python -m src.data.clean_financial_data walmart
python -m src.data.clean_financial_data target
python -m src.data.clean_financial_data costco

Run company analysis:

python -m src.analysis.profitability walmart
python -m src.analysis.working_capital walmart
python -m src.analysis.free_cash_flow walmart
python -m src.analysis.financial_health walmart

Build the comparison dataset:

python -m src.analysis.company_comparison

Run forecasts:

python -m src.models.revenue_forecast walmart
python -m src.models.revenue_forecast target
python -m src.models.revenue_forecast costco

Build and query SQLite database:

python -m src.data.build_database
python -m src.data.query_database

## Limitations

This project is for learning and portfolio purposes. It is not investment advice.

Important limitations:

- SEC XBRL tags vary across companies and filing years.
- Some metrics are unavailable when companies do not report the required tags.
- Working-capital metrics are most meaningful for inventory-heavy businesses.
- Retail metrics should not be blindly applied to banks, insurers, or software companies.
- Forecasts are simple baselines and should not be treated as precise predictions.
- Scenario assumptions are illustrative and not company guidance.
- The app currently uses simple annual models, not advanced valuation or investment models.

# Corporate Financial Health & Working Capital Analysis

## Overview

This project is an end-to-end financial analytics platform that uses SEC Company Facts data to analyze public companies across revenue growth, profitability, working capital, free cash flow, forecasting, scenario analysis, SQL querying, and dashboarding.

The project started with Walmart and expanded to compare Walmart, Target, and Costco. It is currently retail-focused because working-capital metrics such as inventory days, payables days, and cash conversion cycle are most meaningful for inventory-heavy businesses.

## Data Source

The project uses the SEC Company Facts API.

Example SEC endpoint:

```text
https://data.sec.gov/api/xbrl/companyfacts/CIK0000104169.json
```

Raw and processed datasets are ignored by Git because they can be regenerated by rerunning the pipeline.

## Key Metrics

The project calculates:

- Revenue growth
- Operating margin
- Days Sales Outstanding (DSO)
- Days Inventory Outstanding (DIO)
- Days Payables Outstanding (DPO)
- Cash Conversion Cycle (CCC)
- Operating cash flow
- Capital expenditures
- Free cash flow
- Revenue forecasts
- Scenario analysis outputs

Core formulas:

```text
DSO = Average Accounts Receivable / Revenue * 365
DIO = Average Inventory / Cost of Revenue * 365
DPO = Average Accounts Payable / Cost of Revenue * 365

CCC = DSO + DIO - DPO

Free Cash Flow = Operating Cash Flow - Capital Expenditures
```

## How to Run

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Fetch SEC data:

```bash
python -m src.data.fetch_data walmart
python -m src.data.fetch_data target
python -m src.data.fetch_data costco
```

Check tag compatibility:

```bash
python -m src.data.check_tags walmart
python -m src.data.check_tags target
python -m src.data.check_tags costco
```

Clean data:

```bash
python -m src.data.clean_financial_data walmart
python -m src.data.clean_financial_data target
python -m src.data.clean_financial_data costco
```

Run analysis:

```bash
python -m src.analysis.profitability walmart
python -m src.analysis.working_capital walmart
python -m src.analysis.free_cash_flow walmart
python -m src.analysis.financial_health walmart
```

Build the comparison dataset:

```bash
python -m src.analysis.company_comparison
```

Run forecasts:

```bash
python -m src.models.revenue_forecast walmart
python -m src.models.revenue_forecast target
python -m src.models.revenue_forecast costco
```

Build and query SQLite database:

```bash
python -m src.data.build_database
python -m src.data.query_database
```

Run tests:

```bash
pytest
```

Launch dashboard:

```bash
streamlit run app/dashboard.py
```

## Current Insights

Current analysis shows:

- Walmart is the largest company by revenue among the three.
- Costco has shown strong and steady revenue growth.
- Target revenue flattened and declined in the most recent years available.
- Target had a major free cash flow decline in fiscal 2023 because capital expenditures exceeded operating cash flow.
- Walmart has full CCC analysis available, while Target and Costco currently support partial working-capital analysis because accounts receivable is unavailable under the current SEC tag candidates.

## Limitations

This project is for learning and portfolio purposes. It is not investment advice.

Important limitations:

- SEC XBRL tags vary across companies and filing years.
- Some metrics are unavailable when companies do not report the required tags.
- Working-capital metrics are most meaningful for inventory-heavy businesses.
- Retail metrics should not be blindly applied to banks, insurers, or software companies.
- Forecasts are simple baselines and should not be treated as precise predictions.
- Scenario assumptions are illustrative and not company guidance.
